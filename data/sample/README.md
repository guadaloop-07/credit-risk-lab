# Muestras para pruebas

Esta carpeta alojará únicamente recortes pequeños de fuentes públicas o datos
sintéticos claramente etiquetados.

Cada muestra debe incluir en su prueba o documentación:

- fuente y fecha de consulta, si es observada;
- regla de selección de filas y columnas;
- licencia o justificación de redistribución;
- indicación explícita cuando sea sintética.

No se utilizarán muestras para comunicar resultados del portafolio.
